# beats JavaScript SDKs

The browser, Node.js, Vue, Nuxt and React clients of beats, published on npm
as `@revenexx/beats-*`.

- [Usage guide](usage.md): script tag, npm, options, web, product and
  e-commerce analytics, consent, Vue, Nuxt, React, Node.js, privacy notes.
- [Releasing](releasing.md): versions, the release workflow, npm trusted
  publishing.

The repository's [README](https://github.com/revenexx/beats-sdks#readme)
covers installation and development; [CONTRIBUTING](https://github.com/revenexx/beats-sdks/blob/main/CONTRIBUTING.md)
what a change needs.
