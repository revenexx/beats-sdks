# @revenexx/beats-vue

Vue 3 plugin, `useBeats()` composable and Vue Router page views for the beats browser client.

```sh
npm install @revenexx/beats-vue
```

```js
import { createBeatsPlugin } from '@revenexx/beats-vue';

app.use(createBeatsPlugin({ key: 'bk_...', apiHost: 'https://beats.example.com', router }));
```

Documentation: [usage guide](https://github.com/revenexx/beats-sdks/blob/main/docs/usage.md#vue). Source, issues and changelog: <https://github.com/revenexx/beats-sdks>.
