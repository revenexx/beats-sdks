# @revenexx/beats-core

Shared event and item types, normalization, validation and the wire format of the beats clients. You normally do not install it yourself: the other `@revenexx/beats-*` packages depend on it.

```sh
npm install @revenexx/beats-core
```

Documentation: [usage guide](https://github.com/revenexx/beats-sdks/blob/main/docs/usage.md). Source, issues and changelog: <https://github.com/revenexx/beats-sdks>.
